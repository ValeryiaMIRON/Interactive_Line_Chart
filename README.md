# Interactive_Line_Chart
Test Assignment: Interactive Line Chart

Interactive A/B test visualization built with React + TypeScript and Recharts.
The chart visualizes daily conversion rates for multiple variations and includes interactive controls such as zoom, line styles, theme switcher, and data export.

🚀 Live Demo
👉 https://valeryiamiron.github.io/Interactive_Line_Chart/

GitHub Repository
👉 https://github.com/ValeryiaMIRON/Interactive_Line_Chart

📊 Visualization Library

This project uses Recharts — a simple and powerful charting library built on top of React.

✨ Implemented Features
Core Requirements
- Display conversion rate (conversionRate = (conversions / visits) * 100) for all variations
- Show vertical line + tooltip on hover
- At least one variation is always selected
- Dynamic axes scaling based on visible dataset
- All values displayed as percentages
- Responsive layout (671px–1300px)
- Variations toggle selector
- Day / Week aggregation switch

🔥 Bonus Features (Fully Implemented)
- Line Style Selector (Line / Smooth / Area)
- Light / Dark Theme Toggle
- Export Chart to PNG
- Zoom In / Zoom Out / Reset Zoom
- Drag-to-Zoom: Click and drag on the chart area to select a range of dates to zoom into.

🛠 Tech Stack
- React + TypeScript
- Recharts
- CSS Modules
- html-to-image (for PNG export)

📦 Local Setup
Clone the repository:
- git clone https://github.com/ValeryiaMIRON/Interactive_Line_Chart.git
cd Interactive_Line_Chart

Install dependencies:
- npm install

Run locally:
- npm run dev

Build for production:
- npm run build

Deploy to GitHub Pages: 
- npm run deploy
